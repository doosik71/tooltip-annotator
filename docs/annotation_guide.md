# 수작업 annotation 기준

`annotation-editor`로 레이블을 보정하거나 새로 찍을 때 따르는 기준이다. 모든 레이블이 같은 기준을 따라야 검출기가 한 가지 정의를 배우고, 평가 점수도 의미가 있다. 기준이 바뀌면 이 문서를 먼저 고치고, 예전 기준으로 찍은 레이블을 다시 검토한다.

Claude Opus 자동 annotation(`scripts/generate-annotation-opus.py`)의 system prompt도 같은 기준으로 쓰여 있다. 한쪽을 바꾸면 다른 쪽도 맞춘다.

## 1. 대상

- 화면에 보이는 수술도구는 일부만 보여도 모두 찍는다. 도구는 보통 원형 내시경 시야의 가장자리에서 들어온다.
- 어두운 조직 위의 어두운 도구, 조직이나 다른 도구에 일부 가려진 도구를 놓치지 않도록 시야 전체를 확인한다.
- 도구 하나에는 annotation 하나만 둔다.
- 다음은 찍지 않는다.
  - 조직에 이미 남겨진 클립
  - 거즈
  - 빛 반사
  - 시야 바깥의 검은 테두리
- 도구가 하나도 없으면 annotation을 비운 채로 저장한다.

## 2. bounding box

- box는 도구의 보이는 부분 전체(shaft와 작업 끝)를 감싸는, 축에 나란한 가장 작은 사각형이다.
- 가려진 부분은 넣지 않는다. 가려진 부분의 위치를 짐작해 box를 늘리지 않는다.
- tip은 항상 box 안에 있어야 한다. 편집기는 box를 줄이면 tip을 box 안으로 따라 옮긴다.

## 3. tip

### 3.1 기본 정의

- tip은 도구의 원위 작업 끝이다. shaft가 화면에 들어오는 쪽의 반대쪽 끝이다.
- 도구 종류별 위치는 다음과 같다.

| 도구                          | tip 위치                               |
| ----------------------------- | -------------------------------------- |
| grasper, bipolar, clipper     | jaw의 끝                               |
| scissors                      | 날의 끝                                |
| hook                          | 육안으로 보이는 금속 부분의 끝 (3.2절) |
| irrigator 등 끝이 하나인 도구 | 관의 끝                                |

- 작업 끝이 조직이나 다른 도구에 가려 보이지 않으면, 도구에서 가장 원위의 보이는 점을 tip으로 찍는다.
- 찍을 위치는 화면에서 보이는 끝점이다. 가려진 끝의 위치를 짐작해 찍지 않는다.

### 3.2 hook

- hook의 tip은 **육안으로 보이는 금속 부분의 끝**이다. 꺾인 금속 hook의 가장 바깥 끝점에 찍는다.
- 흰색 절연 sheath(플라스틱)의 끝은 tip이 아니다. 금속이 조금이라도 보이면 금속의 끝에 찍는다.
- 금속이 검게 변색되었거나 피가 묻어 붉게 보여도, 금속으로 판단되는 부분의 끝을 찍는다.
- 금속 끝이 조직 속에 묻혀 보이지 않으면, 보이는 금속 부분의 끝(대개 금속이 조직으로 들어가는 지점)에 찍는다.
- hook에는 두 번째 tip을 찍지 않는다.

예전에는 흰색 sheath의 끝을 tip으로 찍은 레이블이 있었다. 이런 레이블은 위 기준으로 고친다.

### 3.3 두 번째 tip (`tip2`)

- 벌어진 가위나 bipolar forceps, grasper처럼 끝이 뚜렷이 둘로 나뉘어 보이는 도구에만 두 번째 tip을 찍는다. 각 jaw(또는 날)의 끝에 하나씩 찍는다.
- 두 끝이 20 px 이내이면 두 번째 tip을 찍지 않고 tip 하나만 찍는다.
  - 편집기는 모든 tip 둘레에 반지름 20 px 점선 원을 그린다. 다른 끝이 이 원 안에 있으면 tip 하나로 충분하다.
  - 20 px는 평가 지표 tip F1@20의 허용 거리와 같다.
  - 두 tip을 20 px 이내로 찍어도, 편집기가 저장할 때 두 점의 평균 하나로 합친다.
- 한쪽 jaw의 끝이 가려져 하나만 보이면, 보이는 끝 하나만 tip으로 찍는다.
- `tip`과 `tip2`에는 순서가 없다. 어느 끝을 먼저 찍어도 된다.

## 4. 판단이 어려울 때

- 같은 장면을 프레임마다 다르게 찍지 않는 것을 우선한다. 앞뒤 프레임에서 찍은 방식을 확인하고 그에 맞춘다.
- 이 문서로 정할 수 없는 경우가 반복되면, 기준을 정해 이 문서에 추가한 뒤 찍는다.
